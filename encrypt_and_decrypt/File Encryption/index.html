Lock any file with a password, then unlock it again. Encryption happens on your own device with the browser's Web Crypto API. Your files and password never leave this page.

How encryption works

  1. Stretch the password. PBKDF2 runs SHA-256 600,000 times with a random salt, so each guess costs an attacker real time.
  2. Pick a fresh IV. 12 random bytes make every encryption unique, even for the same file and password.
  3. Encrypt and seal. AES-256-GCM encrypts the file together with its name and type, and computes a tag over the header and ciphertext.
  4. Verify on the way out. Decryption recomputes the tag. A wrong password or one changed bit, and nothing is released.
Built with the Web Crypto API (crypto.subtle): PBKDF2-HMAC-SHA256 key derivation and AES-256-GCM authenticated encryption. No libraries, no server, no tracking.
