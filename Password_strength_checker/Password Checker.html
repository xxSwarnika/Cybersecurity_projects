Keystone Password Checker

Tests a password against four rules: length, randomness, uniqueness and common mistakes. It also estimates entropy and how long an attacker would need to guess it. Nothing you type is sent anywhere or saved.

Method: character-pool entropy (length × log₂ pool size), reduced for every predictable segment the checker finds: dictionary words, look-alike substitutions, personal info, sequences, repeats and years. Passphrases are scored per word. This is an estimate for learning purposes, similar in spirit to Dropbox's zxcvbn but much simpler.
